# Open Adventure Compendium

Astro web app for browsing and filtering tabletop roleplaying adventures, characters, locations, and encounters from a Sanity-powered content library.

## Features

- Filterable adventure search by author, edition, theme, duration, recommended level, and party size
- Dynamic adventure pages with linked characters, locations, encounters, and campaign guide references
- Sanity CMS integration with [GROQ](https://www.sanity.io/docs/groq) queries and typed content helpers
- Responsive Astro pages enhanced with React components for interactive filters and page tabs
